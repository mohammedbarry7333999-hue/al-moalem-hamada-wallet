# المعلم حمادة للحوالات

تطبيق محفظة إلكترونية تجريبي للتحويلات وإدارة المحافظ.

## الهوية البصرية
- اللون الأساسي: الأسود.
- اللون المميز: الذهبي.
- اللغة: العربية.
- اتجاه الواجهات: RTL.

## العملات
- الريال اليمني YER
- الريال السعودي SAR
- الدولار الأمريكي USD

## الخدمات
- إنشاء حساب وتسجيل الدخول.
- عرض المحافظ والأرصدة.
- إرسال واستقبال الحوالات التجريبية.
- سجل العمليات.
- الملف الشخصي.

## التقنيات
- Flutter
- NestJS
- PostgreSQL
- React

## تنبيه
هذا المشروع تجريبي، ولا يستخدم أموالاً حقيقية أو خدمات حوالات فعلية.
